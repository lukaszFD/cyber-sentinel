Threat scale (1–5)

Table cyber_sentinel.dic_threat_levels.

  • Description and Recommended action are inserted into the AI prompt as [[THREAT_SCALE]]. The AI uses them to word its verdict and the recommended action in analysis_pl, so keep them short and unambiguous. The description is also the threat_label shown in the Grafana threat explorer and alert views.
  • Malicious decides which scores every Grafana view counts as malicious (malicious statistics, daily trends, threat explorer, threat alerts). The views read this table at query time, so a change is retroactive — historical verdicts are re-counted immediately. Malicious levels must be a contiguous top range (e.g. 4–5 or 3–5).
  • The scores themselves are produced by the rule engine (see Simulator); editing this page never changes a score.
  • The number of levels is fixed at five: the rule engine, the prompt (proposed_score: integer 1-5) and the foreign key on stored verdicts all assume 1–5. Adding or removing a level is a code change, not something this page can do safely.

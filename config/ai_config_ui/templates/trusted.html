Trusted infrastructure ("big players")

Table cyber_sentinel_ai.trusted_infrastructure, read by compute_threat_score() on every observable.

What a match does in the rule engine
  • Step 1 — up to vt_big_player_noise_max VirusTotal detections are treated as noise (level CLEAN).
  • Step 5 — the final rule score is capped at 2 (Monitor) unless ThreatFox names a malware family. A match therefore prevents "Malicious" verdicts and e-mails for that host.
Match types
  • as_owner — case-insensitive substring of the VirusTotal AS owner ("google" matches "Google LLC"). Minimum 4 characters.
  • domain_suffix — the domain itself and every subdomain ("microsoft.com" matches "update.microsoft.com").
Do not add hosting anyone can rent (AWS, Azure VMs, OVH, Hetzner, DigitalOcean, GitHub) — attackers run C2 servers there and the cap would hide them. Disable an entry instead of deleting it if you are unsure; the change log keeps the history.

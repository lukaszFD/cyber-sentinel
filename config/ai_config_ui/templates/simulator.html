Scoring simulator

Two ways to run it:
  • Calculate — a "what-if" calculator. You type in what VirusTotal, ThreatFox and URLhaus would return and the simulator runs the same rule engine (compute_threat_score()) the n8n workflow uses, with the current settings and trusted infrastructure. No external request is made.
  • Fetch live data & calculate — asks the real APIs first, exactly like the workflow: VirusTotal by IP, then ThreatFox (by IP) and URLhaus (by domain) only if VirusTotal passes the gate. The results fill the form, so you can tweak them afterwards and press Calculate. Without an IP the domain is resolved directly against Unbound — not through Pi-hole — so the lookup never enters the real n8n work queue.
Nothing is written to the database. The domain name matters for the allow-list check, domain_suffix trusted entries and the URLhaus lookup.
